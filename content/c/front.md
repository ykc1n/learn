# Before you begin

This is an original study companion for the second edition of *The C Programming Language*. It follows the chapter topics without reproducing the authors’ prose or exercises. Use **Import your PDF** to add your own complete copy to the local reader, including its title pages, prefaces, chapters, appendices, and index. The PDF remains on this computer.

## How to work through the book
Read a subsection, trace its examples with pencil and paper, then write a small program from memory. Compile with warnings enabled. Keep a note about each mistaken assumption: what you predicted, what happened, and the rule that explains it. Take the chapter quiz after reading, and the section exam after a group of chapters.

## Edition and toolchain
The second edition teaches ANSI C (C89/C90). Some operating-system examples are Unix-specific. Later C revisions add features that should not silently be treated as part of the 1988 language. For practice on a machine with GCC, `cc -std=c90 -Wall -Wextra -pedantic file.c -o program` checks the older dialect. Modern projects commonly choose a newer standard deliberately.

## A learning loop
1. Predict a result before running a program.
2. Compile and fix diagnostics.
3. Run several inputs, including empty input and boundary values.
4. Explain what each object stores, its type, and its lifetime.
5. Review wrong quiz answers rather than memorizing their positions.

Reading completion and quiz mastery are tracked separately. A quiz or exam passes at 80%. An active day uses America/Phoenix calendar dates. Progress is a single personal profile shared across your devices on this Wi-Fi.
